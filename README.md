# Дипломная работа: Калькулятор срока годности со встроенным Telegram-ботом

Веб-сервис на базе **Django** для автоматизированного учета и контроля сроков годности пищевых продуктов и медикаментов с системой мгновенных push-уведомлений через **Telegram Bot API**.

## 🚀 Ключевой функционал
* **Учет продуктов:** Добавление позиций с указанием дат производства, окончания срока годности и температурного режима хранения.
* **Интеграция с Telegram:** Автоматическая отправка уведомлений пользователям о продуктах, у которых истекает срок годности.
* **Безопасность данных:** Реализовано строгое разделение сред (разработчик/продакшн) с использованием переменных окружения.

---

## 📊 Архитектура базы данных (ER-Диаграмма)

Проект спроектирован по реляционной модели и приведен к третьей нормальной форме (3NF).

### Текстовое описание сущностей:
1. **User (Пользователь):** Встроенная модель Django для авторизации и изоляции данных.
2. **Profile (Профиль, Связь 1:1 с User):** Расширяет модель пользователя. Хранит `telegram_chat_id` для адресации уведомлений ботом.
3. **Product (Продукты, Связь M:1 с User):** Содержит наименование, критические даты (`manufacture_date`, `expiration_date`), температуру хранения и расчетный статус свежести.

*Визуальная схема структуры таблиц доступна в корневом файле: `myapp_models.png`.*

## 🛠 Технологический стек
* **Backend:** Python 3.14+ / Django
* **Database:** SQLite 3 (Локально)
* **API Integration:** HTTP-запросы к Telegram Bot API через библиотеку `requests`
* **Environment:** `python-dotenv` для изоляции конфигурационных данных

## ⚙️ Инструкция по локальному развертыванию

### 1. Клонирование и подготовка окружения
```bash
git clone <url_вашего_репозитория>
cd expiration_calculator
python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или venv\Scripts\activate  # Для Windows
pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте в корне проекта файл `.env` на основе шаблона `.env.example`:
```ini
SECRET_KEY="ваш_секретный_ключ_django"
DEBUG=True
TELEGRAM_BOT_TOKEN="ваш_токен_от_botfather"
```
*Внимание: файл `.env` внесен в `.gitignore` и никогда не попадет в открытый доступ.*

### 3. Миграции и запуск сервера
```bash
python manage.py migrate
python manage.py runserver
```
